# جِسر (Jisr) — قاموس عربي · فرنسي · ولوف

موقع ثابت (Static Site) بسيط — بدون Backend وبدون أي بناء (build step)، يعمل مباشرة على GitHub Pages.

## الملفات
- `index.html` — الصفحة الرئيسية
- `style.css` — التصميم
- `script.js` — منطق البحث والتصفية (يعمل بالكامل في المتصفح)
- `data/words.json` — قاعدة الكلمات (عربي / فرنسي / ولوف)

## كيف ترفعه على GitHub وتشغّله مجانًا (GitHub Pages)

1. أنشئ مستودع (repository) جديد على GitHub.
2. ارفع كل الملفات في هذا المجلد إلى المستودع (بنفس البنية، خصوصًا مجلد `data/`).
3. من إعدادات المستودع Settings → Pages، اختر:
   - Source: `Deploy from a branch`
   - Branch: `main` (أو `master`) والمجلد `/root`
4. احفظ، وانتظر دقيقة، هيديك GitHub رابط زي:
   `https://username.github.io/repo-name/`

لا يوجد أي API خارجي ولا مفاتيح سرّية — البحث كله محلي داخل المتصفح عن طريق ملف `words.json`، فمناسب تمامًا لاستضافة GitHub Pages المجانية.

## توسيع القاموس
لإضافة كلمات جديدة، افتح `data/words.json` وأضف عنصرًا جديدًا بنفس الشكل:

```json
{ "ar": "الكلمة", "fr": "traduction", "wo": "baat wolof وإلا null", "cat": "التصنيف" }
```

إذا لم تكن متأكدًا من الترجمة الولوفية، اترك `"wo": null` بدل تخمينها — الموقع سيعرض تلقائيًا "غير متوفر".

## ملاحظة عن الدقة
القاموس الحالي يضم نحو 180 كلمة أساسية شائعة (أرقام، تحيات، عائلة، أفعال، صفات...). ترجمات الفرنسية موثوقة، أما الولوف فمُدرجة فقط للكلمات التي تتوفر لها مصادر موثوقة — الباقي متروك فارغًا عمدًا بدل تعبئته بترجمات غير دقيقة.
